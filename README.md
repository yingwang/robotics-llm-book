# 把语言模型装进机器人

> 这不是一本单纯传授如何训练 VLA 的教科书，而是一份在将语言模型植入物理实体、按下部署按键之前，必须经历的系统工程决策指南。

📖 在线阅读: **<https://yingwang.github.io/robotics-llm-book/>**

---

## 这是什么

这是一部面向 2024–2026 年具身智能浪潮的工程架构与系统思考之作，专为以下三类读者撰写：

1. 熟悉 Transformer 架构与预训练范式，看得懂 RT-2 架构图，却在走向物理世界闭环时缺少清晰学习路径的算法工程师；
2. 深耕传统机器人控制与规划多年，面对具身大模型转型浪潮，在现成框架（如 LeRobot）与自研训练流水线之间权衡，且急需评估遥操作数据规模与收益边界的从业者；
3. **具备机器学习基础、初涉机器人学的新探索者**。面对社交媒体上眼花缭乱的演示视频，渴望看透各家机构真正的技术底牌与商业赌注，判断未来数年的产业走向。即便略过个别专业机械控制术语，亦能顺畅把握各章的核心逻辑。

全书主体共 14 章（外加 3 篇前置入门篇），以"端到端与分层架构之辨"为核心标尺，切入 14 个真实物理与工程命题：感知表征、动作生成、接触抓取、空间导航、长程任务、仿真到现实、数据飞轮、评测基准、安全边界、硬件选型、落地部署、团队资本以及未来演进。

各章均以工业一线的真实工程张力开篇，穿插代表性公开演示、权威文献与行业真实数据，辅以清晰的架构权衡矩阵与启发式思辨练习。

## 立场

序言立下六条鲜明的工程立场，贯穿全书始终：

- 反 **端到端必胜论**：长程规划、状态回退与结构化几何推理，仍非单一单体 VLA 能够完全消化。
- 反 **人形必然论**：在半结构化作业场景中，轮式底盘协同复合机械臂的能效、精度与经济性往往远超双足构型。
- 反 **仿真已死论**：神经渲染大幅缩小了视觉表征鸿沟，但非平滑接触力学的刚度突变与摩擦接触依然构筑了坚固的物理壁垒。
- 反 **Demo 即真理**：解构业界常见的五种选择性演示手段，穿透视觉表象直击闭环鲁棒性。
- 反 **遥操作数据万能论**：剖析 1k、10k 与 100k 数据的工程拐点，阐明越过万级门槛时分层先验与自动化合成的必要性。
- 反 **对齐等同具身安全论**：严谨区隔语义层、软件控制层与底层硬件力矩保护三个不同时间尺度的安全防线。
