# 把语言模型装进机器人

> 这不是一本单纯传授如何训练 VLA 的教科书，而是一份在将语言模型植入物理实体之后，每天面对真实世界物理约束时必须经历的系统工程决策指南。

本书面向 2024–2026 年具身智能演进浪潮中处于关键抉择期的工程师与研究者：
- 熟悉 Transformer 的训练细节，能够读懂 RT-2 的网络拓扑，却在尝试让机械臂在物理世界闭环时缺少清晰的工程航标；
- 刚刚从 NLP、CV 或强化学习领域转入机器人研发团队，背负着在限定周期内构建可靠物理交互系统的工程压力；
- 面对行业内密集发布的演示视频，渴望剥离光环与剪辑手法，从物理接触、控制带宽与状态分布的角度看清技术本质与代际差距。

**阅读建议**：建议优先阅读序言与第 1 章，建立全书统一的工程判别坐标系。后续四个部分按脉络通读体验最佳，但各章均保持独立的工程自洽性，可直接翻阅当前工作面临瓶颈的对应章节。各章末尾附有启发式练习，意在引导读者审视自身的真实系统与测试记录，提出更具穿透力的工程质询。
