# 第 6 章 长程任务

> 第 1 章确立的系统判别标尺，在本章触及最具挑战性的物理维度：**一旦任务的连续交互时程突破两分钟，单体端到端策略便会呈现出系统性的行为崩溃**。这种退化并非源于高频随机噪声，而是根植于因果拓扑与状态机记忆的结构性缺失。本章将深入解构这一失效机制，阐明为何单纯堆砌网络参数与数据规模无法从数学上消除这一长程鸿沟。

---

在具身机器人的实机测试中，曾记录过这样一段发人深省的餐后清理测试：双臂 VLA 机器人执行收拾餐桌任务，目标是将散落的餐具依次移入水池，随后回程清理桌面水渍。前 60 秒的表现极其流畅自然：机械臂精准抓取每一个瓷碗，运动轨迹平滑，入池放置时未发生任何硬性碰撞。

然而在第 90 秒，系统出现了一个令人深思的病态行为：**它将刚刚平稳放入水池的瓷碗重新抓取取出**，再次稳稳摆放回餐桌中央，稍作停顿后，又重新伸手抓取，再次放回水池。

在长达数分钟的时间里，机械臂以完美的动作一致性重复着这一来回搬运的死循环，各关节力矩与伺服电机平稳运转，没有任何底层报错，直到工程师拍下急停按钮。

逐帧复盘多模态数据流会发现，策略的每一个单步前向推断在局部均处于高置信度区间：当前帧视觉呈现桌上有碗，策略便触发抓取流形；抓取后感知到水池区域，便触发放置流形；而在放置完成重置视点后，视野中重新捕捉到残留器皿，局部策略便再次触发抓取反射。**任务层级的全局因果状态在端到端网络内部根本不具备显式连续性表示**。网络的前向推断退化为了当前瞬态几何输入的无记忆模式匹配（Pattern Matching）。在起始阶段，状态流形与专家演示数据严密重叠；随着微小扰动不断累积，系统逐渐漂移至未见过的混合中间态，最终退化为纯粹的局部瞬态反射。

这一经典失效案例揭示了一个核心工程事实：**长程任务的稳定性瓶颈，并非单纯的数据规模不足，而是系统架构缺乏显式的因果分层与时序状态抽象**。

### 端到端长程退化的四重力学与数学根源

单体 VLA 模型在突破长时程连续操作时遭遇的断崖式退化，可以严格归结为四个相互交织的维度：

**数据分布的时域截断**。真实遥操作示教轨迹的有效时长大多聚集在 10 至 60 秒之间。这一特征受限于操作员生理专注度的持续时间常数、单位时间标注成本的非线性增长，以及人工对停顿重试片段的主动剪辑。即使将庞大的训练预算倾斜于特定长序列（如连续衣物折叠），策略也仅能在受限的同分布场景下维系数分钟的准静态稳定，一旦迁移至因果依赖更复杂的开放环境，时域注意力便迅速发散。

**上下文窗口（Context Window）的表征带宽瓶颈**。在 30Hz 双目连续视频流下，视觉特征 Token 化每秒吞吐数千个高维向量。即使骨干网络支持长上下文，在数分钟连续推断后，自注意力机制依然会面临显存膨胀与早期时序特征被过度稀释的困境；而滑动窗口的截断机制则直接抹除了早期历史的因果锚点，使机器人彻底遗忘前置子任务的完成状态。

**复合累积误差（Compounding Errors）的发散**。在闭环控制中，下一离散时间步的输入状态直接依赖于上一时间步的物理执行结果。单步数毫米的位姿微小残差在数百步的时间积分下，将导致状态空间发生指数级漂移。经典控制系统依托卡尔曼滤波或状态观测器持续引入确定性修正，而端到端黑盒策略缺乏显式的误差校正与投影流形，累积偏差极易将系统推向分布外死区。

**任务进度状态估计（Task Progress State Estimation）的缺失**。机器人能够通过高精编码器获知关节绝对位置，通过多模态特征识别目标物体的局部几何，但**单体网络内部缺乏显式表征“当前复合任务究竟处于第几阶段”的因果游标**。这一隐式任务进度的模糊，是导致状态机反复震荡与死循环的终极根源。

### 规划与执行的解耦：认知分层的必然性

长程任务的核心解法在于架构解耦：**大模型负责跨时程因果规划（Planning），局部策略专注短时熟练动力学执行（Control）**。

将因果规划强行揉入低层 VLA 策略网络，本质上是将符号因果推理与连续流形控制这两类优化目标截然不同的任务杂糅在一起。分层架构的价值并非单纯为了拟合认知心理学中的双系统理论，而是为了在工程上将不同时间尺度、不同信息密度的优化问题实施严格的解耦与隔离。

---

### 大语言模型作为高层规划器的演进

大语言模型在机器人因果规划领域的演进历程展现了清晰的工程脉络：

**SayCan（Google, 2022）**：开创了“语言常识得分 $\times$ 物理可执行度（Affordance）”的联合决策范式，首次验证了预训练模型能够将开放意图转化为具备物理可行性的离散动作序列。

**Code as Policies（Google, 2022）**：将高层规划的输出形式从单步离散 Token 升级为**可执行的参数化 Python 代码结构**。利用编程语言原生的条件分支（`if-else`）、循环逻辑（`for/while`）与变量作用域，显著提升了因果时序逻辑的表达上限。

**Inner Monologue 与 VoxPoser（2022–2023）**：Inner Monologue 引入多模态感知反馈闭环，赋予 LLM 根据执行异常动态重规划的能力；VoxPoser 则通过 LLM 动态生成三维空间势场（3D Value Map），在语义引导与连续轨迹优化之间建立了可微几何桥梁。

进入 2025 年，工业界已全面收敛至基于参数化技能 API 的分层调度体系：

### 技能接口（Skill API）的工程定义准则

分层架构的成败完全取决于底层技能接口的设计粒度与严密性：

**警惕粗粒度的黑盒 API**。诸如 `clean_kitchen()` 这类语义模糊且跨度巨大的接口，本质上是将长程不确定性重新推回给底层策略，注定引发行为崩溃。

**构建结构化、参数化的原子技能集**。标准的工业级 API 应具备如下特征：
- **精确参数化**：如 `pick(object_id, grasp_pose=None)`、`place(target_pose, surface_id)`、`wipe(contour_polygon, tool_id)`；
- **时域收敛**：单技能物理执行窗口严格限制在 10 至 60 秒之内，精准契合端到端模仿学习的稳定收敛区间；
- **明确的状态断言（Assertions）**：具备可量化的成功/失败判定准则与返回代码；
- **语义边界收敛**：支持针对特定原子技能独立采集数千条演示数据进行微调与版本管理。

**严禁将非受限自然语言直接作为低层控制参数**。高层规划器生成的模糊文本指代，必须经过显式的视觉实体定位（Grounding）模块，解析为确定性的物体 ID、包围盒与三维空间坐标，方可下发至低层控制管线。

### 异常自愈与多级恢复协议

长程任务必须建立完备的容错防御纵深：

1. **瞬态自适应重试（Retry）**：针对微小接触滑脱或感知遮挡等偶发扰动，由底层策略在局部执行瞬时重新对准与抓取；
2. **因果状态重规划（Replan）**：当子任务前置条件失效（如柜门受阻无法开启）时，触发高层 LLM 重构因果子任务拓扑；
3. **人在回路协同干预（Human-in-the-loop / Ask）**：当系统判定自身跌入不可恢复的死区时，主动发起低带宽的人机交互请求。

通过多级恢复机制的协同，系统能够在不依赖完美执行假设的前提下，将整体长程作业成功率推升至工业可用标准。

### 具身系统记忆架构的分层拓扑

相较于纯文本智能体，具身智能的记忆系统必须应对极高的时间连续性与感知带宽挑战：

- **短期感知记忆（Short-term Memory）**：由 Transformer 的注意力上下文维系，覆盖数十秒内的局部高维感知与动作流形；
- **中期因果状态记忆（Working Memory）**：由高层规划器维护的显式任务因果图与离散进度状态树；
- **长期经验记忆（Long-term Epistemic Memory）**：跨任务周期的场景先验与物理属性索引库。

在当前工程实践中，**将状态估计思想引入长程任务进度追踪（Task Progress Estimation）**是保障系统鲁棒性的核心枢纽。通过显式的子任务完成度分类器或自省校验逻辑，系统能够在每一步操作后进行确定性状态判别，从根本上阻断死循环的发生。

---

### 动作分层与任务分层的概念解耦

在系统架构中，必须严格区分两类不同性质的分层机制：

**动作空间分层（Action Hierarchy）**：如 RT-Trajectory 或 RT-H，其层级存在于低层动作解码内部（如先预测空间轨迹草图或粗略动作谓词，再映射至关节角）。其本质是动作生成网络内部的归纳偏置优化，**并不具备处理数分钟长程因果依赖的能力**。

**任务空间分层（Task Hierarchy）**：如 SayCan 或 Code as Policies，其层级存在于离散符号因果层与连续控制层之间。各层接口清晰解耦，具备完备的日志审计与错误拦截能力，是攻关长程复杂任务的唯一可行路径。

## 练习

1. **分析长程实机视频的时空衰减点**：调取一段长时程具身演示视频，使用精确计时工具记录系统从起始执行到首次出现位姿漂移、动作僵滞或因果倒退的时间节点。分析该时刻对应的物理环境扰动与网络注意力变化。
2. **解构 SayCan 的规划提示工程**：审视 SayCan 原始文献中的 Prompt 结构设计，分析其如何通过少量示例（Few-shot Demonstrations）约束大语言模型的因果输出空间，推导其在面对未定义物体时的逻辑回退行为。
3. **拆解复合家务任务的原子技能集**：针对“制作简易三明治并清理台面”这一复合长程任务，将其分解为严密的参数化 Python 伪代码流水线。明确定义每一个原子技能的输入参数、执行时限、前置校验与后置成功断言。
4. **设计任务进度状态估计器**：构建一个双重校验机制：在机械臂完成“放置杯盏”技能后，分别从末端力矩变化、双目视觉分割与空间几何重投影三个独立通道设计数学判据，判定该子任务是否在物理意义上真实闭环。
