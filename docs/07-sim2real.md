# 第 7 章 仿真到现实

> “通用动作模型兴起后，动力学仿真便不再关键”是具身智能领域最常见的认知偏差之一。**真实的工程演进恰恰相反：物理仿真在当下不仅未被淘汰，反而在系统安全、状态穷举与高频动力学学习中占据了更为核心的生态位**，其应用范式经历了一场深刻的重构。

---

在双足人形机器人的实机闭环测试中，曾记录过这样典型的一幕：一台 1.4 米高的人形机器人在 Isaac Sim 仿真环境中连续平稳行走了 8 个小时，测试覆盖了平地、5 度斜坡以及台阶等复杂地形，在 0.3 m/s 至 1.2 m/s 的全速度区间内均展现出教科书般的收敛收敛收敛性与奖励函数曲线。

然而当部署至物理实机时，系统在迈出第一步的瞬态便发生倾覆。

高速摄像机的慢动作回放揭示了这一失效的物理根源：仿真环境中预设的足底与地面静摩擦系数为 0.8，而测试现场的抛光木地板实测摩擦系数仅约为 0.35。策略在仿真中习得的摆动腿推进动力学高度依赖充足的地面切向反作用力；当接触面无法提供预期的摩擦力矩时，足底在毫秒级时间内发生侧向微滑动，整个二阶刚体动力学平衡在 80 毫秒内彻底失稳崩溃。

这一案例深刻折射了现代 Sim2Real 的现实状态：**视觉表征层面的跨域鸿沟正在迅速收敛，但非平滑接触动力学的保真度壁垒依然坚固**。许多初学者容易被光线追踪渲染出的逼真画面所迷惑，将高保真视觉渲染直接等同于动力学一致性，从而在实机接触突变时遭受挫折。

本章旨在厘清物理仿真在现代具身工程中的真实边界：明确哪些环节可以安全依托仿真进行大规模并行训练，哪些环节已属过时范式，而哪些高维非线性接触任务依然必须依赖真实世界物理闭环。

### 一、Sim2Real 十年演化脉络

在深度学习与机器人学交汇的历程中，跨域迁移技术经历了四代核心演进：

**域随机化（Domain Randomization, DR）**：由 OpenAI（Tobin 等，2017）确立的标准工程范式。其核心思想在于：既然无法完全精确消除仿真与物理世界的系统偏差，便在仿真中将一切物理与视觉参数施加高维随机扰动（纹理贴图、光照强度、相机内外参、质量分布与摩擦系数），迫使神经网络在不变特征流形上收敛。当策略对该高维扰动分布具备充分的不变性时，现实世界便可被视作该随机空间中的一个常规样本。

**域自适应（Domain Adaptation, DA）**：通过对抗训练（GAN-style）或特征对齐损失（如 CORAL、DANN），在潜变量空间中强制对齐仿真特征与真实特征的分布流形。其局限在于高度依赖真实数据分布的平稳性假设，而在复杂动态物理交互中该假设极易被打破。

**系统辨识（System Identification, SysID）**：通过精密物理测量直接测定执行器时间常数、连杆惯性张量、减速机传动效率与接触阻尼，并将参数硬编码注入仿真引擎。然而对于非线性齿隙（Backlash）、温度引发的伺服漂移以及橡胶材料磨损，经典辨识方法难以实现全工况高精度建模。

**自动域随机化（Automatic Domain Randomization, ADR）**：OpenAI 在 Shadow Hand 求解魔方任务（2019）中将其推向极致。系统依据策略当前的成功率动态撑大物理扰动区间，自动构建渐进式课程学习（Curriculum Learning）。该方案确凿证明了仿真强化学习能够攻克极高复杂度的灵巧接触，但其伴随的数万 GPU 小时算力开销亦构筑了极高的工程门槛。

### 二、主流物理仿真引擎的生态与技术特质

面对具体的具身工程研发，主流仿真底座展现出各自清晰的技术定位：

**MuJoCo / MuJoCo MJX**：作为分析力学领域的经典之作，MuJoCo 在多刚体接触动力学约束求解（Contact Constraint Solving）上具备极高的数学严密性。DeepMind 开源并推出的 GPU 并行化版本 MJX，使得大规模并行强化学习得以在物理一致性极佳的刚体流形上高效展开。

**PhysX / Isaac Sim / Isaac Lab**：依托 NVIDIA Omniverse 平台，Isaac 体系在**高保真光线追踪渲染、大规模 GPU 并行与软硬件生态整合**上占据显著优势。其是端到端具身基座模型（如 GR00T）与世界模型协同训练的核心基础设施；但在微观接触力矩与柔性体形变的精确度上，仍需精细的参数校准。

**Drake**：由 MIT 与 TRI 主导的开源动力学框架，专注于高精度多体动力学、符号化拉格朗日力学与可微接触建模。其专为基于凸优化的轨迹规划（Trajectory Optimization）与模型预测控制（MPC）设计，追求严格的能量守恒与物理保真度。

**Genesis**：由 CMU 团队主导的统一物理仿真平台，尝试在 GPU 原生架构下统一解算刚体、柔性体、织物、流体与颗粒介质，代表着多物理场可微仿真的前沿探索方向。

**Habitat 与 SAPIEN**：前者聚焦于大规模室内三维环境中的视觉语言导航与移动操纵评估；后者专注于多关节铰接机构（Articulated Objects，如门窗橱柜、抽屉旋钮）的高保真交互数据集构建。

### 三、打破“VLA 终结仿真论”的工程审视

针对“大规模实机遥操作配合互联网视频足以完全替代动力学仿真”的观点，工程实践给出了明确的否定反驳：

**长尾极限工况的物理不可穷举性**。在真实的开放部署中，机器人必须应对极低概率但极高危险性的物理事件：突发障碍物冲击、接触面突发润滑流体、儿童近距离阻挡干涉。在物理实机上采集此类破坏性长尾演示在经济与安全上完全不可行，高吞吐仿真环境是生成此类极端应力测试样本的唯一途径。

**系统级安全认证与红蓝对抗（Red Teaming）**。一台数十公斤自重、具备高动态力矩输出的人形机器人，在算法权重迭代后，绝不允许未经仿真压力测试直接进入人机共融环境。仿真是构建全场景安全防御包络与碰撞边界校验的唯一无风险验证场。

**底层高动态运动控制的自主探索学习**。人类遥操作示教天然偏向低动态准静态轨迹，无法提供高动态平衡自恢复、跌倒阻尼翻滚与高频碰撞顺应等极限动作流形。当前人形机器人的高动态行走策略（如 HumanPlus、ASAP），全部依赖仿真环境中的高吞吐强化学习进行状态探索，随后蒸馏迁移至实机系统。

### 四、视觉与接触表征的跨域收敛差异

评估 Sim2Real 难度时，必须严格区分感知流形与动力学流形：

**视觉表征跨域鸿沟的实质性收敛**。得益于 RTX 光线追踪（Path Tracing）技术的成熟、自监督视觉基础模型（DINOv2, SigLIP）对于光照几何变化的高维不变性，以及通用扩散与世界模型的预训练迁移，多模态策略在仿真环境与真实物理环境中的视觉特征差异已显著收敛。SimplerEnv 等评测基准表明，视觉操纵任务在仿真与实机上的策略表现已具备极强的正相关性（$R > 0.9$）。

**接触动力学物理鸿沟的客观存在**。与视觉层面的平滑收敛截然相反，微观接触动力学依然构筑了坚固的物理壁垒：
- **库仑摩擦定律的微观失效**：静摩擦向滑动摩擦切换的瞬态非线性、微观粗糙度与接触温漂无法在解析方程中精确闭环；
- **柔性织物与薄壳形变**：位置动力学（PBD）在大变形下存在网格穿透失真，而有限元方法（FEM）难以维系毫秒级高频控制闭环；
- **连续介质与颗粒流体**：液体晃动与粉末流动的高保真仿真需要巨大的颗粒计算算力；
- **机械磨损与迟滞效应**：末端执行器硅胶衬垫的物理磨损会导致接触刚度随使用周期发生不可逆漂移。

因此，**接触密集型的精密装配与柔性操纵策略，在当前依然必须以真实世界的物理交互数据为核心支柱**。

### 五、新兴仿真范式：从视频重建到神经物理生成

近年来，Sim2Real 领域涌现出若干代表性的技术演进路径：

**Real2Sim2Real 闭环重建**。以 NVIDIA Cosmos 与 RoboCasa 为代表的技术，允许工程师通过单目实拍视频直接反推并重建三维仿真场景，并在生成的三维环境中利用强化学习进行海量数据增广，最终将策略蒸馏回实机。该方案将高精度仿真场景的搭建周期从数周压缩至数小时。

**程序化场景生成（Procedural Generation）**。依托 ProcTHOR 与 Holodeck，利用大语言模型自动编排室内几何拓扑与物体布局，可批量合成数万个结构各异的虚拟测试空间，为导航与空间语义推理策略提供近乎无限的场景多样性。

**3D 高斯泼溅（Gaussian Splatting）稠密物理环境**。将真实场景的稠密 3DGS 辐射场无缝嵌入仿真环境，在维系 30Hz 以上实时渲染性能的同时，提供了极其逼真的物理背景交互视差。

### 六、仿真强化学习向实机蒸馏的工业标准范式

在底层运动控制与动态平衡领域，“仿真教师策略训练 $\to$ 传感器受限学生策略蒸馏”已成为行业通行的标准范式：

1. **特权信息教师策略（Teacher Policy）训练**：在并行物理仿真器中，依托 PPO 等算法训练具备全局真实状态观测（全量刚体速度、接触力、未扰动地面摩擦）的特权策略网络；
2. **冻结教师并构建受限观测空间**：固定教师网络权重，构建仅输入真实物理传感器数据（IMU、关节编码器、稀疏视觉）的学生网络架构；
3. **行为克隆与时序状态蒸馏（Distillation）**：利用监督学习迫使学生网络在有限感知输入下拟合教师网络的动作分布；
4. **注入动力学域随机化与时序扰动**：结合 ASAP 等时序扰动技术增强策略对机械通信延迟与传动死区的鲁棒性，最终实现零样本实机部署。

这一工程范式彻底打破了底层运动控制对人工遥操作的依赖，支撑了现代双足与四足机器人在复杂非结构化地形中的全自主运动能力。

## 练习

1. **解构前沿双足 Sim2Real 文献的失效分析**：研读 ASAP、HumanPlus 与 ANYmal 相关文献中的失效章节，归纳其实机部署失败的深层机理，分析微观时钟抖动与瞬态法向力突变对连续步态的破坏路径。
2. **建立多物理引擎选型决策矩阵**：针对一个包含“双臂协同擦拭餐桌并收纳柔性餐巾”的复合任务，分别对比 MuJoCo MJX、Isaac Lab 与 Genesis 在该任务建模中的优势与瓶颈。
3. **评估域随机化的理论边界**：重读 Tobin 等（2017）开创性文献，论证为何对于低维刚体位姿估计，域随机化能够实现平滑迁移，而对于高维粘弹性接触（如硅胶夹爪捏持软体），单纯的参数随机化极易导致策略保守乃至发散。
4. **核算实机物理失真预算**：列出你当前机器人硬件平台上难以在仿真中精确建模的非线性物理项（如谐波减速机传动反隙、线缆拖拽阻力矩、驱动器热衰减效应），设计一套软硬件协同的容差补偿方案。
