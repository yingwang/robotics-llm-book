# 第 9 章 评估（解构演示假象）

> 本章直面具身智能领域最敏感的工程现实。要在这一领域建立长期的技术判断力，工程师与架构师必须掌握两项核心能力：**如何穿透外界演示视频的视觉假象**，以及**如何在团队内部建立严密、求真且具备统计置信度的评测基准**。

---

不妨审视一段在社交媒体上引发轰动的经典演示视频：在长达 30 秒的一镜到底镜头中，双臂人形机器人面对杂乱的桌面，在工程师下达“整理餐桌”的指令后，接连将易拉罐投入回收箱、将香蕉摆入果盘、将餐具规整排布并叠放好餐巾，最终呈现出干净整洁的桌面。该视频在发布数小时内播放量破千万，舆论随之涌现关于通用具身智能即刻到来的乐观预测。

然而，若将该视频以逐帧慢动作进行工程解构，隐藏的物理破绽便逐一浮现：

第一处：在第 3 秒至第 4 秒之间，存在一个长达 27 帧的镜头硬切（Cut）。画面从机器人躯干特写瞬间切换至桌面俯视机位，机械臂末端执行器在切镜头的瞬间，从桌面外围直接跳跃至可乐罐上方 5 厘米的预抓取位姿。**在未公开的这一秒时间内，系统实际上跳过了一段关键的近场引导动作**，而该阶段往往包含多次姿态微调甚至失败重试。

第二处：在抓取香蕉的片段中，视频播放帧率由标准的 30 fps 降至约 22 fps，画面被施加了约 1.4 倍的局部加速。**原本耗时 4 秒的低速抓取在成片中被压缩至 2.8 秒**。在物理世界中，长达 4 秒的单体抓取反映了底层策略极其保守的推断时延，而这一动力学迟滞在快节奏剪辑中被彻底掩盖。

第三处：背景中的果盘空无一物，桌面上所有工件的几何外形、表面反光率与摆放间距均处于严格受控的基准状态。**这并非系统在真实开放场景中的泛化表现，而是针对训练集分布实施的物理环境重现**。

此外，机器人接近各类物体时的抓握角度高度单一；指令措辞与技术报告中的训练语料完全一致；结尾处迅速切换视角，规避了全景视场下可能存在的未复位细节。

随后，此类演示片段被载入商业融资简报，被大众媒体解读为技术奇点的降临，进而引发同业团队对自身研发节奏的盲目激进化。

演示（Demo）本质上是一场高度工程化与公关化的能力呈现。本章的核心目的，并非单纯揭示公关包装手法，而是**确立一套穿透视觉表象、测定系统真实闭环鲁棒性的工程评测方法论**。

### 选择性演示的五类经典工程手法

在行业公开的演示视频中，常见的选择性展示策略可归纳为以下五个梯次：

**手法一：多轮试错与成功片段拼接**。系统在相同初始条件下连续执行数十次，仅截取极少数闭环成功的轨迹。观众感知到的是 100% 的完美成功率，而实机背后的首发通过率可能不足 10%。其识别特征在于：不同片段间机械臂的初始位姿与物体几何完全定格，缺乏任何随机扰动。

**手法二：机位切换遮蔽关键控制故障**。在机械臂逼近目标、执行高动态接触或因果转换的关键瞬态，画面切入操作员特写或大范围环境广角；当视点切回时，关键接触已然完成。**在 30 秒以内的演示中若存在多次非必要机位跳切，通常暗示着系统在跳过特定的轨迹震荡或人工干预**。

**手法三：局部时间重采样掩盖控制迟滞**。当策略网络在前向推理中发生高计算负载，导致闭环控制频率由 30Hz 跌落至数赫兹并引发电机抽搐卡顿时，通过视频后期时间抽帧与 1.3 至 1.8 倍的局部加速，可在视觉上营造出流畅平滑的连续交互假象。其识别特征在于观察背景环境中的自然运动（如流水、织物飘动或环境人物步频）是否存在非自然的时间畸变。

**手法四：作业空间与物体分布过度收敛**。尽管训练数据集涵盖上百种物体，演示中出现的始终是少数高度规则的标准几何体（标准可乐罐、规整木块）。未引入任何非典型几何、高光反光介质或柔性流体样本。

**手法五：控制指令的硬编码过拟合**。演示中所采用的自然语言指令与训练集中的示教提示词一字不差。系统本质上执行的是针对特定指令的轨迹模板检索，而非开放意图的因果推理。一旦对输入语句施加同义改写或语义颠倒，策略的执行成功率便呈现断崖式衰减。

### 公开基准测试集（Benchmarks）的价值与局限

相较于非受控的公开演示，学术基准测试集提供了标准化的跨团队比对平台：

**SimplerEnv（Stanford, 2024）**：在仿真环境中高保真重构了 RT-1、Octo 及 OpenVLA 的真实操作任务，验证了高质量仿真评测与实机策略表现的高度统计相关性（$R > 0.9$）。然而其评测边界主要局限于刚体桌面操作，对流体与复杂柔体接触的评估能力依然有限。

**LIBERO（UT Austin, 2023）**：定义了空间、物体、目标与长程四大评测套件，适合定量检验策略的多任务泛化能力，但在真实物理光影与机械动力学多样性上仍显简化。

**FurnitureBench（KAIST, 2023）**：坚持采用真实物理机械臂进行复杂家具组装评测，提供了完备的遥操作轨迹与标准实机测试协议，是当前极具说服力的物理交互基准之一。

**Colosseum（CMU, 2024）**：专注于扰动（Perturbation）条件下的鲁棒性评估：施加极端光照变化、杂乱背景注入、多干扰物堆叠与未见姿态扰动。主流 VLA 模型在其最严苛的分布外测试集上，成功率通常剧烈退化至 30% 以下，直观揭示了当前基准模型的真实鲁棒性短板。

**RoboCasa（NVIDIA / Stanford, 2024）**：在仿真中构建了包含上百种日常任务与复杂场景的多样化测试集，通过大规模程序化环境变化对策略的几何与语义鲁棒性进行压力测试。

必须清醒认识到：**所有公开基准测试均在特定约束流形内构建，无法直接等同于非结构化真实客户环境下的系统可用性**。单纯针对特定 Benchmark 进行指标刷分，极易陷入过拟合测试集的局部最优。

### 真实世界评测的统计置信度与样本规模

在物理实机上开展评测伴随着显著的时间与设备损耗开销。单次实机试验（Trial）通常包含 30 秒至 2 分钟的操作时程，外加环境复位（Reset）与传感器校准周期。一个专职评测单元单日通常仅能完成 100 至 200 次独立测试。

在有限样本下，必须引入严格的二项分布统计置信度度量：

若在 $N=100$ 次试验中观察到 $k=70$ 次成功（名义成功率 70%），依据 Wilson 分数区间（Wilson Score Interval）计算的 95% 置信区间约为 $[60.4\%, 78.1\%]$，区间跨度达 17.7 个百分点。

若试验规模缩减至 $N=10$ 次且取得 7 次成功，其 95% 置信区间急剧扩大至 $[39.7\%, 89.2\%]$。在此统计精度下，70% 与 50% 或 80% 在数学上不具备可区分的统计显著性。

```python
import statsmodels.stats.proportion as prop

# 计算 Wilson 置信区间示例
k, n = 70, 100
ci_lower, ci_upper = prop.proportion_confint(k, n, alpha=0.05, method='wilson')
print(f"Success Rate: {k/n:.2%}, 95% CI: [{ci_lower:.2%}, {ci_upper:.2%}]")
```

**工程铁律：任何不标注样本总量 $N$ 与统计置信区间的成功率数据，均不具备严谨的科学与工程评估价值**。在系统决策中，必须杜绝基于数十次偶然测试所作出的架构收敛判断。

### 研发预算中的评测配比准则

在具身算法流水线中，评测环节的资源分配应当占据极其显著的权重：

一个标准的 VLA 微调周期通常耗费数十天卡 GPU 算力与大量遥操作示教；然而在评测阶段，部分团队仅投入极少数工时进行定性验证。**评测资源的匮乏直接导致系统对边缘工况与分布外崩溃模式一无所知**。

在成熟的具身工程体系中，**评测资源投入应当达到训练总预算的 30% 至 50%**。这包含：
1. 构建涵盖分布内（In-Distribution）、轻度扰动（Near-OOD）与重度干扰（Far-OOD）的多级测试基准；
2. 每个测试工况执行不少于 100 次的确定性重复试验；
3. 全面记录多维度失效日志与物理接触时间序列。

### 失效模式归因分析矩阵（Failure Analysis）

单纯统计成功与失败的二值结果，无法为算法迭代提供可操作的收敛线索。每次物理试验的失效必须被严密分类至归因矩阵中：

- **感知漏检与误识（Perception Miss）**：模型未在特征空间内准确定位目标或产生几何幻觉；
- **因果规划失误（Planning Error）**：识别正确但触发了错误的子任务逻辑或动作时序颠倒；
- **几何接触偏差（Contact Failure）**：末端位姿逼近合理，但接触点脱离摩擦锥或接触深度偏差导致未形成有效约束；
- **动力学抓取滑脱（Grasp Slip）**：成功建立接触但在转移过程中因惯性或握力不足发生相对滑动；
- **分布外行为失控（Model OOD）**：环境出现未见视觉特征，策略前向推断输出极端离群动作；
- **硬件与驱动异常（Hardware Fault）**：伺服电机过热失步、总线通讯抖动或传感器掉线。

```
[100 次物理试验失败归因矩阵]
Perception Miss:  ████████████ 35%  -> 研发动作: 增强开放词表分割与视点增强
Contact Failure:  ████████████████ 45% -> 研发动作: 引入高频触觉闭环与阻抗控制
Grasp Slip:       ████ 12%            -> 研发动作: 增加末端法向力预紧度
Model OOD:        ██ 8%              -> 研发动作: 注入边界扰动样本微调
```

### 工业级部署评测指标体系

当系统从实验室走向工业与商业交付时，评估基准必须从单一任务成功率全面转向连续动力学与系统可用性指标：

**平均故障间隔时间（Mean Time Between Failures, MTBF）**：系统在无需任何人工干预的前提下，连续执行复合长程任务的无故障平均物理运行时间。商用服务机器人的初期准入门槛通常为 2 至 4 小时，工业流水线场景则要求达到 8 至 24 小时以上。

**人工干预率（Intervention Rate）**：平均每运行小时需要远程操作员接管或现场人工介入的次数。该指标直接决定了车队规模化运营的商业单位经济模型（Unit Economics）。

**任务级置信良率（Task Success Rate with CI）**：在明确测试协议（Protocol）与固定样本量下达成的硬性良率指标。
